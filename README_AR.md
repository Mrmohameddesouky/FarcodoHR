# Farcodo HR — النسخة التأسيسية
تطبيق مكتبي مستقل لإدارة الموظفين والعقود باستخدام Python وPySide6 وSQLite.

## التشغيل على Windows
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```
قاعدة البيانات تحفظ في مجلد المستخدم `.farcodo_hr` وتبقى بعد إغلاق البرنامج.

## الأيقونة
ضع الأيقونة الأصلية باسم `assets/farcodo.ico`.

## مراحل التطوير
1. **المرحلة التأسيسية:** إعداد مشروع مستقل وواجهة عربية وهوية بصرية.
2. **إدارة الموظفين:** إضافة وتعديل وحذف وبحث مع تخزين SQLite.
3. **إدارة العقود:** ربط العقود بالموظفين وحفظ التواريخ والرواتب والبدلات.
4. **المراحل التالية:** استيراد PDF وOCR، دورة مراجعة واعتماد، تقارير، نسخ احتياطي، واختبارات وإصدار Windows.

## الحالة الحالية
هذه نسخة تأسيسية أولية تتضمن واجهة عربية وإضافة/تعديل/حذف/بحث للموظفين والعقود وتخزينًا دائمًا. لم تُنفذ بعد ميزات OCR واستيراد PDF وسير اعتماد المستندات والتقارير والنسخ الاحتياطي؛ لا تعتبر جاهزة للإنتاج قبل استكمال هذه الميزات واختبارها.
